AerisGo — Customer Website and Admin Dashboard

The supplied Sign In and Sign Up screenshots are the visual reference for the authentication pages.
Both pages use the same split-screen layout:
- cream form area
- AerisGo logo at top-left
- centered form
- airplane image on the right
- matching typography, spacing and button styling

Main flow:
Home → Sign In / Sign Up → Logged-in Home → Search Results → Flight Details → Seat Selection → Passenger Details → Booking Confirmation → Booking Success → My Account

Account flow:
My Account → Check-in → Meals → Baggage

Other:
Sign Up → OTP
Sign In → Forgot Password → Reset Password

Admin dashboard:
Open admin.html for the operations dashboard shown in the supplied dashboard reference. It includes overview analytics and management screens for flights, bookings, aircraft, crew, users, and an interactive seat map. Demo record changes are stored in the browser's local storage.
On the login screen, click “Use demo account” to fill the demo email and password, then click “Sign in to dashboard.”

Technology:
The customer booking flow is static HTML and CSS. The admin dashboard uses HTML, CSS, and vanilla JavaScript. Both parts are front-end prototypes; they do not provide server-side authentication or a production database.
